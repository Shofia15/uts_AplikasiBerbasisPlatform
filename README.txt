Cara menjalankan:

2. Buka folder di VS Code.
3. Jalankan index037.html menggunakan Live Server (disarankan).
4. Uji navigasi, katalog, dan form.

Bukti screenshot yang perlu diambil sendiri di browser:
1. Network tab: pilih index037.html, tunjukkan Request Method GET dan Status Code 200.
2. Katalog tampilan mobile dan desktop (gunakan Device Toolbar).
3. Form gagal: Nama Lengkap = Budi 123, pilih mobil, Lama Sewa = 0.
4. Form berhasil: Nama Lengkap = Budi 123, pilih mobil, Lama Sewa = 1.
